# AvatarMix mesh retargeting

This component provides the mesh retargeting solver used by GSReshape. Build `cloth-fit/build/PolyFEM_bin` using [Installation](../docs/installation.md#native-tools), then run the pipeline's `cloth_fit_reshaping` stage as described in the [main README](../README.md#usage).

Solver input options are described in [the retargeting reference](README.upstream.md#script-settings). See [the extension notes](src/polyfem/modification_summary.md) for human-mesh fitting details.

Based on [Intersection-free Garment Retargeting](https://github.com/Huangzizhou/cloth-fit). See [upstream documentation](README.upstream.md), [LICENSE](LICENSE), and [Third-party notices](../THIRD_PARTY_NOTICES.md).
