# AvatarMix image refiners

SeamFix and FullbodyFix extend Difix3D+ with trainable adapters. Use the [training guide](../docs/training.md) and the [installation guide](../docs/installation.md). The training entrypoint is `scripts/train_swapfix_lora.py`; public experiment names are `seamfix` and `fullbodyfix`.

Based on [NVIDIA Difix3D+](https://github.com/nv-tlabs/Difix3D). Original attribution is retained in [README.upstream.md](README.upstream.md); its examples describe the upstream project, not this release. See [LICENSE.txt](LICENSE.txt) and the [third-party notices](../THIRD_PARTY_NOTICES.md).
