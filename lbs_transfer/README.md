# AvatarMix skinning-weight transfer

This component transfers body-model skinning weights to reconstructed avatar meshes. Install its environment using [Installation](../docs/installation.md), then run the pipeline's `lbs_transfer` stage as described in [Data preparation](../docs/data_preparation.md#convert-and-reconstruct-avatars).

Based on [Robust Skin Weights Transfer](https://www.dgp.toronto.edu/~rinat/projects/RobustSkinWeightsTransfer/index.html). See [upstream documentation and citation](README.upstream.md), [LICENSE](LICENSE), and [Third-party notices](../THIRD_PARTY_NOTICES.md).
