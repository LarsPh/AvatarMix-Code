# AvatarMix surface reconstruction

This component uses NeuS2 to reconstruct initial surfaces from multi-view images. Follow [Installation](../docs/installation.md#native-tools) to build the headless executable and Python bindings, then [Data preparation](../docs/data_preparation.md#convert-and-reconstruct-avatars) to run reconstruction through the AvatarMix pipeline.

Based on [NeuS2](https://github.com/19reborn/NeuS2). See [upstream documentation and citation](README.upstream.md), [LICENSE.txt](LICENSE.txt), and [Third-party notices](../THIRD_PARTY_NOTICES.md).
