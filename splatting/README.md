# AvatarMix Gaussian avatars and GSReshape

This module contains avatar reconstruction, reposing, garment reshaping, static rendering, and Gaussian fine-tuning. Follow the [data preparation guide](../docs/data_preparation.md) and [installation guide](../docs/installation.md). Use the top-level pipeline for cross-module workflows.

Based on [SplattingAvatar](https://github.com/initialneil/SplattingAvatar).
